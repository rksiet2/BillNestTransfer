AUDIT REPORT: What Was In Place Before (Summary)
────────────────────────────────────────────────────────────────────────────────

Feature                     Status    Details
────────────────────────────────────────────────────────────────────────────────
Expiry Dates                YES       expiresAt in payload, checked at activation & validation
Perpetual Licenses          YES       expiresAt: null means never-expiring
Machine Binding             YES       SMBIOS UUID → SHA256, bound to specific hardware
Module Tiers                YES       food | rooms | both (cheaper plans possible)
Customer Name Storage       YES       hotelName in payload
Cryptographic Signing       YES       Ed25519, unhackable without private key
Offline Validation          YES       Entirely local, no internet calls
Grace Period                NO        Hard expiry check — app goes dark immediately
Remote Revocation           NO        No mechanism to revoke already-issued license
License Renewal             YES       Dashboard can "extend" by re-issuing
Copy-Protection             YES       Machine ID embedded in signature
Multi-Terminal Support      YES       Only HOST needs license, Clients bypass check
In-App License Info         NO        No Settings screen showing expiry/modules/name
Expiry Warning Banner       NO        No advance notification before expiry
Runtime Re-check            NO        License only checked at startup, never again
Revoke Action in Dashboard  NO        Delete just removed vendor history record

WHAT WAS BUILT IN THIS SESSION
────────────────────────────────────────────────────────────────────────────────

1. GRACE PERIOD (7 days after expiry)
   File: electron/licensing.cjs
   - Instead of throwing immediately when expiresAt < Date.now(), allows a
     7-day grace window
   - Returns payload with gracePeriodDaysLeft field when in grace
   - getLicenseStatus() returns { valid: true, payload: { gracePeriodDaysLeft: N } }
     during grace period
   - Returns { valid: false, reason: 'EXPIRED' } after grace ends
   - getLicenseStatus() now extracts expiresAt from blob even on failure so
     ActivationScreen can show the actual expiry date
   - activateLicense() maps 'EXPIRED' to human message:
     "This license has expired. Contact the vendor to renew before activating."

2. IN-APP LICENSE INFO PANEL (Settings page)
   File: src/components/Settings/LicenseInfoSection.jsx  [NEW]
   File: src/components/Settings/SettingsPage.jsx  [MODIFIED]
   - Shows: licensed hotel name, modules (Food Billing / Room Booking badges),
     issued date, expiry date with color-coded status badge, Machine ID
   - Status badges:
       Perpetual  → blue
       > 30 days  → green
       <= 30 days → yellow
       <= 7 days  → red
       Grace      → amber ("Grace period — Nd left to renew")
       Expired    → red
   - Only shown in Electron desktop (window.api present), never on mobile
   - Placed before the "Files & Records" section in Settings

3. PERIODIC RUNTIME RE-CHECK (every 1 hour)
   File: electron/main.cjs
   - setInterval checks license status every 60 minutes after app starts
   - If license transitions from valid to invalid (e.g. revoked blob applied),
     calls app.relaunch(); app.exit(0) → shows Activation screen
   - Only runs for HOST/standalone installs; Client terminals are never gated

4. EXPIRY WARNING BANNER (14 days advance warning)
   File: src/App.jsx
   - Dismissible yellow banner at top of app shell when <= 14 days until expiry
   - "Your license expires on [date] — contact your vendor to renew."
   - Changes to "only Nd left!" when <= 7 days remain
   - Dismissed state stored in sessionStorage (doesn't re-appear within session)
   - NOT shown during grace period (that state → Activation screen instead)

5. SELLER DASHBOARD — REVOKE ACTION
   File: license-dashboard/server.cjs
   - Added POST /api/licenses/:id/revoke route
   - Re-issues license with expiresAt = yesterday
   - Customer's app blocks access on next hourly recheck or restart once
     they apply the new expired blob

   File: license-dashboard/public/app.js
   - Added "Revoke" button (amber) in each license row's actions
   - Revoke handler calls /revoke endpoint, shows new expired blob in result
     overlay with instructions: "Send to customer — once they apply it, blocked"
   - Updated Delete confirmation text to clearly state it only removes vendor
     history, does NOT revoke access on customer's machine
   - Result overlay heading/hint text now resets correctly for generate vs revoke

   File: license-dashboard/public/style.css
   - Added .btn-link.btn-revoke (amber color)

   File: src/index.css
   - Added license info panel CSS classes (.license-info-*, .license-module-badge,
     .license-expiry-badge and variants)
   - Added expiry warning banner CSS (.expiry-warning-banner, .expiry-warning-banner-dismiss)
